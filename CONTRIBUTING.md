# Contributing

Bug reports, test results with your headsets, and pull requests are all
welcome.

USBPods is an open-core project: this GPL-3.0 firmware shares most of its
source files with the commercial **USBPods Full** firmware, maintained by
the same author. So that a merged change can keep shipping in both
editions, by submitting a pull request you agree that:

1. the contribution is your own work, offered under this repository's
   license (GPL-3.0-only with its linking exception), and
2. you additionally grant the maintainer a perpetual, irrevocable,
   non-exclusive right to use and relicense your contribution as part of
   the proprietary USBPods Full firmware.

If you do not want (2) to apply to a particular change, say so in the pull
request and it will be considered for Lite-only code paths instead.
